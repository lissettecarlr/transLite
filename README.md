# 久远的翻译工具

轻量 Chrome 双语翻译扩展。支持 Google 和自带 API Key 的兼容 AI 接口，默认按需翻译屏幕附近的内容，滚动后继续。

## 使用

1. 安装后点击工具栏图标，确认待译文字的接收方并授权访问翻译服务。
2. 点击“翻译此页面”。部分失败时可重试未完成内容；暂停保留译文，“恢复原文”移除译文。
3. 弹窗可设置“仅本次翻译”“此网站始终翻译”“此网站不自动翻译”。始终翻译只在明确授权的网站生效。
4. AI 模式在设置中选择服务商、填写地址及 API Key，点击“保存并测试连接”。测试发送固定示例，可能产生服务商费用。

思考模式默认关闭；根据模型家族和接口选择参数。千问预设为 `qwen3.8-flash`，另有 `gpt-5.4-nano` 快捷按钮。本机 vLLM 的 Qwen 请求使用模板参数，远程 Qwen 使用顶层开关；服务是否实际关闭思考取决于模型及服务端支持。模型快捷按钮只切换模型，服务提供方预设会填写地址与模型。其他地域和阿里云工作空间专属地址可手动填写。

远程接口要求 HTTPS；本机模式允许 localhost、127.0.0.1、::1 的 HTTP。地址可填写 API Base 或完整 `/chat/completions` 路径，扩展会规范化。

API Key 默认仅保存在当前浏览器会话。需要长期保存时可选择密码加密保存，重启后用密码解锁；密码不会保存。忘记密码可清除后重新配置。所有设置存储在本机，不启用 Chrome 同步。详见 [隐私说明](privacy.html)。

默认快捷键 Alt+T，可从设置页进入 Chrome 快捷键管理修改。默认保护输入框、编辑器、代码、隐藏内容和不翻译标记；菜单/按钮翻译需在设置中开启。Linear/LiteLLM 的内置词典继续可用，自定义 LiteLLM 控制台地址在高级设置中填写。

支持普通 HTTP(S) 网页；Chrome 内部页面、应用商店、内置 PDF、跨域 iframe 和 Shadow DOM 不属于当前完整支持范围。Google 通道有网络与频率限制，扩展不承诺无限免费或服务可用性；AI 接口费用由服务商收取。

## 安装与测试

Chrome 120+：打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，加载 `src`。商店现有条目：[久远的翻译工具](https://chromewebstore.google.com/detail/dkjbikoamkfpmmfaodleccdefonkjebb)。

运行时没有 npm 依赖。开发测试需要 Node.js 20+、Python 3.9+；以下命令会安装测试使用的 Chromium：

```sh
npm ci
npx playwright install chromium
npm test
npm run package
```

测试包括请求与权限边界、密钥加密、取消/重试、真实 DOM、动态网页以及安装后的 MV3 扩展。网络测试只连接本机模拟服务，不使用真实 API Key，不消耗付费模型额度。

安装测试仅在临时 Manifest 中预授权本机模拟服务，以绕过无头模式无法操作的原生权限弹窗；正式 Manifest 保持按需授权。原生授权弹窗和真实服务的验收项见 [发布说明](docs/release-1.1.0.md)。

打包脚本使用明确的文件清单，校验 Manifest、页面脚本和样式引用，排除同步冲突副本、测试及开发文件。生成 `dist/transLite-1.1.0.zip`。源码重载后刷新原网页。本版本使用新的配置结构，不迁移旧配置。

## 仓库内容

- `src/`：扩展源码、运行所需图标及扩展内隐私说明。
- `tests/`：单元测试和浏览器测试；示例凭证与域名均为测试夹具。
- `scripts/package.py`：发布包构建与校验脚本。
- `docs/`：版本说明及人工验收步骤。
- `package.json` / `package-lock.json`：开发依赖及锁定版本，均需提交。
- 根目录 `privacy.html`：用于部署公开隐私页面；`src/privacy.html` 用于扩展内展示。修改时同步两份，打包脚本会检查一致性。

依赖目录、ZIP、测试截图、报告、环境变量文件和同步冲突副本由 `.gitignore` 排除。本地历史资料可放在 `.local/`，不提交到仓库。发布包通过打包命令生成，不在源码仓库中保存二进制 ZIP。

## 实现

- `config.js`：设置验证、服务预设和公开页面偏好。
- `vault.js`：密码派生与本机加密密钥。
- `background.js`：授权、站点脚本、受信任设置操作与任务生命周期。
- `translation.js`：分批、限流、重试和内存缓存；最多 3 个 HTTP 请求并行，超时 25 秒，临时 HTTP 错误最多重试两次。
- `content.js` / `dom.js`：分段、视口附近调度、局部变更扫描、译文插入与恢复原文。

已完成的缓存按服务、接口、模型、目标语言、提示词和思考策略区分；在途去重仅限同一任务，使不同标签页可独立取消。初次识别仍会扫描普通页面 DOM，动态更新优先扫描局部内容。
