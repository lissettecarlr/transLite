久远的翻译工具 · 隐私说明

最后更新：2026 年 9 月 17 日 · 适用于 1.1.0

本扩展用于网页双语翻译。开发者不运行收集译文或浏览记录的服务器，本扩展不包含广告、分析埋点或远程执行代码。翻译所选内容需要由您确认的第三方服务处理。

处理的内容与用途

手动翻译时，扩展读取当前网页符合翻译条件的文字，优先处理屏幕附近的内容；开启某网站的自动翻译后，会在该网站打开页面、滚动及内容更新时继续处理。右键翻译处理您选中的文字。编辑区域、密码输入、代码和标记为不翻译的内容默认跳过。页面本身可能包含私人文字，请按需要决定是否翻译。

Linear 和 LiteLLM 的部分界面标签通过随扩展提供的词典在本机替换；适配器允许远程翻译的未收录内容仍遵循所选服务的授权。本扩展不会发送整页 HTML、表单输入值或浏览历史清单。

发送给谁

选择 Google 时，待译文字发送至 https://translate.googleapis.com。选择 AI 接口时，文字及该接口的 API Key 发送至您配置的地址；默认支持千问、OpenAI 及其他兼容服务。接收方在扩展弹窗和设置页明确显示。启用前需确认数据用途并授予所需访问权限，服务失败不会静默转交另一服务。

远程服务必须使用 HTTPS。明确选择本机服务时，允许通过 HTTP 访问 localhost、127.0.0.1 或 ::1。网络请求不携带网页 Cookie 或页面来源地址；服务商仍可能获得网络连接必需的信息（例如 IP 地址），并依其条款处理请求。测试连接仅发送一段固定示例，AI 服务商可能计费。

保存在哪里、保存多久

  • 普通设置、网站偏好和服务确认记录保存在本机扩展存储中，不通过 Chrome 同步。
  • API Key 默认只保存在浏览器会话内存中；后台休眠后仍可读取，但浏览器重启或扩展重新加载、禁用、更新后需重新输入或解锁。
  • 选择“用密码加密记住新密钥”时，密钥使用 AES-GCM 加密后保存在本机，密钥由您的解锁密码经 PBKDF2 派生。解锁密码不保存；解锁后的 API Key 仅保留在本次会话中。忘记密码时，可清除加密副本并重新填写 API Key。
  • 网页内容脚本不接收 API Key，不能直接访问保存密钥的扩展存储区域。
  • 成功译文缓存在扩展后台内存中，最多 500 条，每条有效期最多 30 分钟；后台重启即清空，不持久化保存翻译历史。临时任务状态随标签页导航、关闭或浏览器会话结束清除。

您可以控制什么

在弹窗选择“仅本次翻译”“此网站始终翻译”或“此网站不自动翻译”；“停止翻译”停止当前任务与后续自动续译，“恢复原文”移除本页译文。始终翻译的网站偏好仍会在下次打开页面时生效，若需长期关闭，请改为“不自动翻译”。停止会取消尚未发送的请求并尝试中止在途请求；已发送的内容无法撤回，不保证服务商停止计费。

设置页提供清除密钥、加密副本和临时译文缓存的入口，也可移除网站偏好。Chrome 扩展管理页可撤销网站访问权限；卸载扩展会移除本机扩展数据。第三方服务已收到的数据由其保留与删除政策管理。

权限与反馈

activeTab 用于用户触发后临时访问当前页面；scripting 用于按需注入翻译脚本；storage 保存设置与会话状态；contextMenus 提供选中文字翻译。访问翻译服务及自动翻译网站的权限按需请求，不在安装时要求访问所有网站。

如有疑问，请使用 Chrome 网上应用店详情页的开发者联系或支持入口。提交问题时请勿附上 API Key 或私人网页原文。我们会在数据处理方式变化时更新本说明及产品内提示。
